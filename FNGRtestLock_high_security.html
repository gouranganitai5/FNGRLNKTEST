ℹ️ About This Test & Architecture

This web application demonstrates a real WebAuthn-based authentication workflow. It does not directly read or capture your physical fingerprint or facial features.

Your Android OS and browser handle all biometric inputs and device security verification. The application only receives a cryptographic WebAuthn assertion. The optional WebAuthn PRF output is used as an authenticator-bound key-encryption input; it is not biometric data.

Integration Architecture: The underlying BiometricAuthManager JavaScript module handles feature detection, credential binding via IndexedDB metadata, and WebAuthn calls without external dependencies.
